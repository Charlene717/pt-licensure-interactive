👤 使用者切換／管理

同一台裝置可建立多個使用者，作答進度互不干擾。
切換使用者後會自動重新整理。
    新增使用者

    💾 匯入／匯出 JSON 備份

    JSON 可用於跨裝置同步進度。iOS 會自動開新分頁，請用「分享 → 儲存到檔案」儲存。匯出時會詢問檔名，預設為「日期時間_使用者」。
    📤 匯出
    「匯出全部」含所有使用者與所有測驗。「匯出單個」只含選定的一位使用者。
    📥 匯入
    「匯入全部」會完全取代本機所有資料。「匯入單個」適用於單一使用者備份檔（也支援從全部備份中只匯入一位），會取代選定使用者的資料，其他使用者保留。
